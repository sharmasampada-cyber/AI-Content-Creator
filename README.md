# 🤖 AI Content Creator Suite

An AI-powered content creation application that helps users generate engaging and platform-specific digital content using Artificial Intelligence.

## ✨ Features

- 📱 Instagram Caption Generator
- 📝 Blog Post Generator
- ▶️ YouTube Description Generator
- 🐦 Tweet Generator
- 💼 LinkedIn Post Generator
- 🎭 Multiple Tone Options
- 🌐 English, Hindi and Hinglish Support
- 📏 Short, Medium and Long Content
- 🏷️ Automatic Hashtag Generation
- 🔄 Regenerate Content
- ⬇️ Download Generated Content
- 📜 Content Generation History

## 🛠️ Technologies Used

- Python
- Streamlit
- OpenAI API
- python-dotenv
